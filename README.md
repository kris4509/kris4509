## 👋 About Me

I'm a Computer Science student at **Egerton University** (Class of 2027), currently interning as a Software Engineering Intern at **Skyfalke Technologies** in Nairobi. I like building things end-to-end — I'll design the database schema in the morning and be arguing with a CSS flexbox bug by evening.

Most of what I build starts from a real annoyance: an attendance sheet that took too long to fill in became **WorkPulse**. Wanting to practice for interviews without pestering friends became **PrepAI**. I ship fast, test as I go, and I'm just as comfortable in a fintech payment integration as I am animating a button hover state.

When I'm not shipping code, I'm usually tinkering with side tools — automation scripts, small trading utilities, and the occasional over-engineered personal project that didn't need to be that complex, but here we are. 🚀
